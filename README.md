# Star News

একটি সহজ PHP + MySQL ভিত্তিক নিউজ ওয়েবসাইট। এখানে অ্যাডমিন পেজ থেকে সংবাদ যোগ করা যায় এবং হোম পেজে সর্বশেষ সংবাদ দেখানো হয়।

## রান করার নির্দেশনা

1. `schema.sql` ফাইলে থাকা SQL স্ক্রিপ্ট রান করে ডাটাবেজ ও টেবিল তৈরি করুন।
2. প্রয়োজন হলে এনভাইরনমেন্ট ভ্যারিয়েবল সেট করুন:

```
DB_HOST=localhost
DB_NAME=starnews
DB_USER=root
DB_PASS=
```

অথবা লোকাল ডেভেলপমেন্টের জন্য SQLite ব্যবহার করতে পারেন:

```
DB_DRIVER=sqlite
DB_PATH=./data/news.db
```

3. লোকাল সার্ভার চালান:

```
php -S localhost:8000
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন।
